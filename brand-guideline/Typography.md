# Clight Brand System — Typography & Type Hierarchy

## 1. Typeface Families
- **Primary Interface**: `Inter` / `Plus Jakarta Sans`
  - Clean, neutral neo-grotesque designed for maximum readability across screens.
- **Display & Editorial**: `Cormorant Garamond` / `Playfair Display`
  - High-contrast serif for literary elegance, philosophy headers, and artistic moments.

## 2. Hierarchy Scale (1.250 Major Third)
- **Display**: 48px / 1.1 Line Height / Weight 600
- **Heading 1**: 32px / 1.2 Line Height / Weight 600
- **Heading 2**: 24px / 1.3 Line Height / Weight 500
- **Body Large**: 18px / 1.5 Line Height / Weight 400
- **Body**: 15px / 1.5 Line Height / Weight 400
- **Caption / Meta**: 12px / 1.4 Line Height / Weight 500
